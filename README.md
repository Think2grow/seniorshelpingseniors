# Seniors Helping Seniors® Southern Utah

A production-ready, compliance-focused franchise website for Seniors Helping Seniors® Southern Utah, built with Astro, Tailwind CSS, and TypeScript.

## Features
- Fully static, accessible, and professional
- A2P 10DLC and Go High Level SMS compliance
- Franchise-grade navigation, footer, and content
- Accessible contact form with dual SMS consent

## Project Structure
- `/components` – Reusable UI and compliance components
- `/layouts` – Shared page layouts
- `/pages` – All site pages (Landing, Privacy Policy, Terms)
- `/styles` – Global styles and Tailwind setup
- `/public` – Static assets

## Scripts
- `pnpm dev` – Start local dev server
- `pnpm build` – Build for production
- `pnpm preview` – Preview production build

## Setup
1. Install dependencies: `pnpm install`
2. Start dev server: `pnpm dev`
